# Simple Calculator

A GUI-based calculator built using Python and Tkinter for the CodSoft Python Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division by zero handling
- Clear button
- Exit button

## Technologies Used

- Python 3
- Tkinter

## How to Run

```bash
python calculator.py
```
